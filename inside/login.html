管理员入口

本站托管在 GitHub Pages 上，只有静态文件，没有服务器。因此这里不提供账号密码登录——任何写进网页的凭据都等于公开。

当前是公开站点。管理功能不在网页端，请在本机打开 Electron 管理端（_tools/admin）完成写作与发布。
本机预览环境。管理端已在本机运行，直接回到管理端窗口即可编辑。
打开管理端预览
  1. 打开本机管理端，输入本地管理密码解锁。
  2. 在「文章」里新建或编辑，编辑器右侧实时预览。
  3. 在「站点设置」里调整首页标语与 ContactMe 信息。
  4. 点「发布」，管理端会构建、提交并推送到 GitHub。
  5. GitHub Pages 自动更新，通常一到两分钟。

没有网页端登录，也没有可被窃取的网页凭据。
