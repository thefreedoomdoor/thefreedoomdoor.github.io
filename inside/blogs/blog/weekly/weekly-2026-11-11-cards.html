本周经验卡：量化、剪映与裁脸坐标

2026-11-11 583 字 · 2 分钟 经验卡 · ComfyUI · 剪映

本周十七张卡：展开 H3 长度硬编码、剪映批量导入、接触表裁脸三张，其余按类归纳。

三张展开

H3 工作流 length 硬编码 124

现象：改参数想生成别的帧数，输出永远是 124 帧，参数像被忽略。

做法：检查工作流 JSON 里的 length 字段——它被写死成 124，不跟随界面参数。批量修了 6 个工作流，当前在用的 4 个已确认正常。

验证：改请求的帧数后，输出帧数与之一致；批量修复记录写进正式卡，避免下次重查。

剪映批量导入与拖拽

现象：用 computer-use 操作剪映时，导入框选不中多个文件；素材拖不进时间线。

做法：批量导入走「导入 → Ctrl+L 跳目录 → 文件名框输通配符 seg_*.mp4 → 点列表下方空白 → Ctrl+A → 回车」；拖素材必须给 left_click_drag 带 strategy: "event"，默认的 auto 不生效。

验证：时间线片段数等于导入数；素材箱条目数对得上。

接触表裁脸坐标漂移

现象：在 cmp 接触表上按整幅比例目测脸框，连续裁歪；放大复核时找不到脸。

做法：不从 sheet 目测。直接从原图 candidates/keyframes_r2/* 按分数坐标裁，再放大 2–4 倍看；首裁取大框（整格宽 40% × 高 60%），确认后再收紧。

验证：裁出的框在原图居中且含下巴；同一坐标重复裁结果一致。

其余按类归纳

  • 路径基准：cmp\...、candidates\keyframes\...、previs 三类产物都以 pipeline\huichao_ch1\ 为基准，不是 manifest 所在目录。拼路径前先 ls 确认。
  • 盲评质量：淘汰状态只认 status: "cut"；每个候选必须有 evidence{I,C,L,M,D} 每轴 ≥4 字符的可证伪观察，以及 judge{gut_rank、duel、devil.attacks、confidence}。
  • 量化：Q2_K 下图像通路完好、文本通路被抹平，文生图不可用；img2img 不受影响。
  • Python：python -I 会丢工作目录和 PIL，批处理脚本别加；含反引号的 python -c 用双引号包会被 shell 当命令替换，脚本先落盘再跑。
  • 重写数据：json.dump 写回会补一个行尾换行，改字段前先备份并按行 diff；按新剧本重置 manifest 要显式删旧剧本独有的条目，ensure_entries 只增不删。
  • 长文本生成物：45KB 的分镜 JSON 别用 heredoc 传，会 spawn ENAMETOOLONG，直接落盘再自检。
