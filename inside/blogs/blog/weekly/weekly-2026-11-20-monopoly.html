寻宝航线：一天十个版本，把游戏砍到只剩走棋

2026-11-20 1070 字 · 3 分钟 周记 · 直播大富翁

v3.0.0 到 v3.5.0，十二个小时里连发十个版本包：先把藏宝图做成 3D、修登录与鼠标，再把道具、技能牌、碎片换卡整套删掉，礼物表只剩四列。

十个版本包，一条单向的删减线

从上午十一点到晚上十一点一刻，十个包，每个包都带一份完整测试报告。版本号一路往上，功能却在往下减——这天的方向只有一个：把「机制」一件件拿掉，只留下走棋和礼物。

v3.0.0 是起点：新的主播工作台（海绿配黄铜，独立直播状态、礼物账本、实时排名、行动队列，两侧面板可拖动缩放并记住布局），加上重绘的 45° 三维藏宝图——单暖光、纸张与木桌的材质、岛屿礁石旋涡沉船，红叉只标实际到达的位置。同一版里收掉三处硬问题：礼物严格按 UID 绑定并用稳定事件 ID 去重（收到时存一份规则快照，之后改规则不影响待发奖励）、正式认证回包才算「已连接」、以及把 protobuf 里勋章目标的 ID 误认成观众 UID。

v3.1 那一串全是地图与手感：大地图加跟随镜头、蜿蜒航线、随机轻弯（多数站点只留一个偏心缓弯，少量不对称双弯）；v3.1.3 专门修「面板一拖就点不动」——拖动时屏蔽鼠标事件的旧样式，标题栏能拖、按钮也跟着点不了，展开把手还被边缘裁掉。

v3.2.0 开始删

默认二十八站里的五个道具格改成真心话/大冒险，编辑器不再提供道具格；题库按「粉丝/主播 × 真心话/大冒险」四类各扩一轮；登录态换成正式的弹幕节点接口（带签名），匿名仍走旧路径，但把「弹幕令牌被拒」判成可重试，而不是一律算账号有问题；顺手加了「重连直播」按钮，不必重新扫码。

v3.3.0 是这天的分水岭。棋盘每次启动随机生成，格数在 17 到 37 之间浮动；礼物不再需要「入局绑定」，按昵称直接建档；Roll 与走步加了刻意的卡顿——Roll 从十四帧 55ms 改成十帧、停顿从 90ms 递进到 500ms，落定再停 560ms，走步 260ms 放慢到 360ms，三分之一概率插 200ms 停顿。题库重写成 141 条互不重复，把惩罚式的、擦边的文案全删了。

v3.3.1 把「绑定」这套东西彻底抹掉：匿名（拿不到 UID、昵称还被平台打码）也按名字建档，等真实 UID 出现再自动升级。v3.4.0 只修一个细节——真心话大冒险弹窗加了关闭按钮和五秒冷却，关闭不扣行动、不卡队列；冷却标记写在 finally 里，所以想验它得走真正的格子入口，直接调内部函数是测不出来的。

v3.5.0 收尾：道具牌堆、碎片换卡、Boss 弹层、加速/狙击/护盾/冻结/自选点数全部删除，发放逻辑只剩「礼物 → 行动次数 + 碎片」，礼物表压成「礼物 / 价值 / 行动次数 / 碎片」四列。旧存档里的那些字段仍能读，只是不显示也不发放。

验收

交付的是一份单文件离线 HTML，1.4 MB。四套测试：前端 28 项、后端协议 45 项、源码集成 24 项、隔离 exe（mock 模式）27 项，全绿。验收脚本在浏览器里读真实 DOM，确认被删的东西真的不在了——道具面板、换卡按钮、道具芯片、骰子按钮、Boss 弹层全部返回空；页面零错误。

还没进 git

仓库只有本机、没有远程，分支停在「跟随镜头」那条特性分支，这一天的十个包只打了版本标签。要给别人用，还是靠发 zip。

这天的教训都进了经验卡

一次删得太狠：替换默认配置里的一大段数组时，把紧挨着的礼物表一起吞掉了，页面初始化第一行就崩，构建却照样通过。另一次是 protobuf 的字段号——礼物事件里第一个出现的「ID」其实是勋章目标，把它当发送者 UID，多个送礼人会被合并成一个人。两条都单独成卡，见本期的《本周经验卡》。
